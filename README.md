> **An immersive PBL (Problem-Based Learning) game for med students**, built with a cyber-medical dark aesthetic, AI-powered clinical cases, and RPG mechanics.

**🛠️ Stack:** React · Vite · Tailwind CSS · Framer Motion · Firebase · Gemini AI · Lucide React

**✨ Highlights:**
- 🎮 **Gamification mechanics** — XP system, Hardcore Mode, ICU scenarios
- 🤖 **AI-powered diagnostics** — Gemini integration for dynamic clinical cases (patients don't reveal diagnoses — students must deduce from symptoms)
- 🎨 **Dark/Cyber-Medical aesthetic** — Glassmorphism UI with strategic color theory (red reserved for critical/life-threatening scenarios)
- 📚 **PBL methodology applied to code** — punishes shortcut-seeking with XP penalties

🔗 **Live Demo:** [caca-med.vercel.app](https://caca-med.vercel.app)
